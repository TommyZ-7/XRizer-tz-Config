# tz-controller AppImage Packaging Implementation Plan

> **Historical note (rename C1, 2026-11-06):** この文書は旧名 `XRizer-tz Config` / `xrizer-tz-config` 時代の設計・実装記録です。現在の名前は `tz-controller` です。本文は現在の名前・パスに更新しています。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tz-controller を linuxdeploy + appimagetool で x86_64 AppImage にし、ローカルと Ubuntu 22.04 CI の両方でビルド・起動検証できるようにする。

**Architecture:** `scripts/build-appimage.sh` が release バイナリ、desktop、仮アイコン、Noto CJK JP、fontconfig、AppRun を AppDir にまとめ、linuxdeploy で非コアライブラリを同梱し、appimagetool で `dist/` に AppImage を生成する。GitHub Actions は同じスクリプトを Ubuntu 22.04 で実行し、Xvfb + FUSE2 で通常起動をスモークテストして artifact / Release に添付する。

**Tech Stack:** Rust/eframe release binary, bash, linuxdeploy 1-alpha-20251107-1, appimagetool 1.9.1, AppImage type 2, Noto Sans CJK JP, fontconfig, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-05-appimage-packaging-design.md`


> **Final implementation note:** the shipped AppImage loads the bundled Noto CJK directly into egui via `TZ_CONTROLLER_FONT` and disables `system_font_fallback`. The final AppImage does not use `fonts.conf`/fontconfig; see the design doc for the v0.1.2 correction.

## Global Constraints

- 対象は Linux x86_64 のみ。AppImage type 2。
- Release 用 AppImage は Ubuntu 22.04（glibc 2.35）でビルドする。ローカルは CachyOS でも同じスクリプトを使う。
- 非コアライブラリは linuxdeploy で同梱する。glibc / libGL / libEGL / libdrm などのコア graphics ライブラリはホストに任せる。
- Noto Sans CJK JP を同梱し、`fonts.conf` + `FONTCONFIG_FILE` で日本語表示を保証する。SIL OFL 1.1 を同梱する。
- AppImage 名: `tz-controller-<version>-x86_64.AppImage`。
- desktop ID / アイコン名: `io.github.tommyz7.TzController`。
- ツールは pinned:
  - linuxdeploy `1-alpha-20251107-1`、SHA256 `c20cd71e3a4e3b80c3483cef793cda3f4e990aca14014d23c544ca3ce1270b4d`
  - appimagetool `1.9.1`、SHA256 `ed4ce84f0d9caff66f50bcca6ff6f35aae54ce8135408b3fa33abfc3cb384eb0`
  - フォールバック Noto CJK `Sans2.004` の `06_NotoSansCJKjp.zip`、SHA256 `bf5b26feb83ee02533d4eb4a127bd90ed9d42bdd7ca7cb6e4030b2f21ef55cc5`
- FUSE2 がない環境では `APPIMAGE_EXTRACT_AND_RUN=1` を使う。README に明記する。
- GPL-3.0-or-later。同梱フォントは SIL OFL 1.1。
- 既存のアプリ挙動は変えない。AppImage 化のために必要な最小限のビルド設定だけを追加する。

## Review Focus

1. **任意の CWD / 最小環境からの起動** — AppImage を別ディレクトリから起動しても、同梱ライブラリ・デスクトップ・フォント設定が解決する（Task 2, 3）。
2. **FUSE2 の有無** — CI では通常起動、ローカルでは `--appimage-extract-and-run` で起動できる（Task 2, 3）。
3. **日本語表示** — 同梱 Noto CJK が fontconfig 経由で使われ、システムフォントも隠れない。起動後スクリーンショットで確認する（Task 2, 3）。
4. **タグ Release** — `v*` タグで artifact と Release の両方が作られ、同名 Release が既にある場合も失敗しない（Task 4）。
5. **コア graphics ライブラリの非同梱** — libGL/libEGL/libdrm を同梱してホストと衝突しない。`ldd` と AppDir 内容で確認する（Task 3）。

## Task 2: Build script and local AppImage

**Files:**
- Create: `scripts/build-appimage.sh`
- Modify: `.gitignore` if needed
- Test: generated `dist/tz-controller-<version>-x86_64.AppImage`

**Interfaces:**
- Consumes: `assets/appimage/*`, `assets/fonts/OFL.txt`.
- Produces: `dist/tz-controller-<version>-x86_64.AppImage`.
- Environment: `VERSION` overrides the Cargo version; `APPIMAGE_TOOLS_DIR` overrides the tool cache (default `target/appimage-tools`).

- [ ] **Step 1: Write the script skeleton**

The script must:

1. `set -euo pipefail`, resolve `ROOT`, `VERSION`, `ARCH=x86_64`.
2. `cargo build --release --locked`.
3. Create `target/appimage-tools`, download pinned linuxdeploy/appimagetool if absent, verify SHA256, `chmod +x`.
4. Locate a Noto CJK font from the paths in the spec; fallback to the pinned `Sans2.004` zip, extract `NotoSansCJKjp-Regular.otf`, verify SHA256.
5. Create `target/appimage/AppDir` with:
   - `usr/bin/tz-controller`
   - `usr/share/applications/io.github.tommyz7.TzController.desktop`
   - `usr/share/icons/hicolor/512x512/apps/io.github.tommyz7.TzController.png`
   - `usr/share/fonts/noto/<font>`
   - `usr/share/doc/tz-controller/OFL.txt`
   - `fonts.conf`
   - `AppRun` (0755)
6. Run linuxdeploy with `APPIMAGE_EXTRACT_AND_RUN=1`:
   ```bash
   "$LINUXDEPLOY" --appdir "$APPDIR" \
     --executable "$APPDIR/usr/bin/tz-controller" \
     --desktop-file "$APPDIR/usr/share/applications/io.github.tommyz7.TzController.desktop" \
     --icon-file "$APPDIR/usr/share/icons/hicolor/512x512/apps/io.github.tommyz7.TzController.png" \
     --custom-apprun "$APPDIR/AppRun"
   ```
7. Run appimagetool with `APPIMAGE_EXTRACT_AND_RUN=1`:
   ```bash
   ARCH=x86_64 "$APPIMAGETOOL" "$APPDIR" "dist/tz-controller-${VERSION}-x86_64.AppImage"
   ```
8. Print the output path and size.

## Task 3: CI build, smoke test, artifact

**Files:**
- Create: `.github/workflows/appimage.yml`
- Modify: none

**Interfaces:**
- Consumes: `scripts/build-appimage.sh`.
- Produces: CI artifact `tz-controller-appimage`, screenshot artifact.

- [ ] **Step 1: Write the workflow**

```yaml
name: AppImage
on:
  workflow_dispatch:
  push:
    tags: ['v*']
permissions:
  contents: write
jobs:
  appimage:
    runs-on: ubuntu-22.04
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y \
            libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
            libxkbcommon-dev libwayland-dev libx11-dev \
            libgl1-mesa-dev libegl1-mesa-dev \
            patchelf squashfs-tools libfuse2 \
            fonts-noto-cjk xvfb xdotool imagemagick x11-utils
      - name: Build AppImage
        env:
          VERSION: ${{ startsWith(github.ref, 'refs/tags/v') && github.ref_name || format('dev-{0}', github.sha) }}
        run: |
          # strip leading v for tags
          if [[ "$VERSION" == v* ]]; then VERSION="${VERSION#v}"; fi
          export VERSION
          bash scripts/build-appimage.sh
      - name: Smoke test under Xvfb
        run: |
          APP=$(ls dist/*.AppImage)
          Xvfb :99 -screen 0 1280x800x24 &
          export DISPLAY=:99
          export LIBGL_ALWAYS_SOFTWARE=1
          sleep 1
          "$APP" > appimage.log 2>&1 &
          APP_PID=$!
          if ! timeout 30 xdotool search --sync --name "tz-controller"; then
            cat appimage.log
            exit 1
          fi
          xdotool search --name "tz-controller" getwindowgeometry
          import -window root appimage-smoke.png
          kill "$APP_PID" || true
      - uses: actions/upload-artifact@v4
        with:
          name: tz-controller-appimage
          path: dist/*.AppImage
      - uses: actions/upload-artifact@v4
        with:
          name: appimage-smoke
          path: appimage-smoke.png
      - name: Release on tag
        if: startsWith(github.ref, 'refs/tags/v')
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          APP=$(ls dist/*.AppImage)
          if gh release view "$GITHUB_REF_NAME" >/dev/null 2>&1; then
            gh release upload "$GITHUB_REF_NAME" "$APP" --clobber
          else
            gh release create "$GITHUB_REF_NAME" "$APP" --title "tz-controller ${GITHUB_REF_NAME#v}" --generate-notes
          fi
```
